| **Description** | PED Toolbox is a native Windows 10/11 desktop app for everyday maintenance (Microsoft Store build). Create restore points and PED-Recovery backups, run diagnostics, open Windows Update settings, run SFC/DISM with confirmation, adjust privacy-related registry policies, search and install apps with winget, clean startup entries and temp files, and toggle hibernate, indexing, and power plans. The Store package does not include the Services profile editor. Every action is user-initiated; destructive steps ask for confirmation. Activity is logged locally to your PC. |
