## Lessons

- 2026-11-09: The repo is PUBLIC. A private URL anywhere in branch history (not just the final tree) blocks merge. Squash is disabled, so the fix is a clean re-cut: new branch from `origin/v3`, check out the approved tree, one commit, verify (diff vs approved tree empty, 1 commit, grep finds no private URL), open a new PR, close the old one unmerged. Happened twice (#12 -> #13, #14 -> #15).
- 2026-11-09: Write private repo names as plain text only (e.g. "repo-rules grok/release-roles.md, private"), never as links.
- 2026-11-09: `fleet.mdc` is generated by the repo-rules sync script; hand edits break `-Check`. Fix it upstream and re-sync.
- 2026-11-09: When moving docs, re-check every relative link that points at the moved files (RISKS, TEAM, PACKAGING had stale `../tasks/` links).
- 2026-10-18: Secrets documentation (SECRETS-MAP) lives in the separate private appkeys repo; PEDToolBox only references it by name.
- 2026-10-18: `.repo-rules/` is a gitignored local snapshot; never commit it.
